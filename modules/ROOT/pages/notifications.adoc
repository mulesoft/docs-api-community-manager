== Release Announcements

Upgrades are applied automatically to Anypoint API Community Manager versions 2.0 and later.

Details about new releases are announced in the API Community Manager release notes.

For further information, contact your MuleSoft customer success representative.

== Downtime

MuleSoft and Salesforce report and monitor platform downtime at https://status.salesforce.com/products/Mulesoft and https://trust.salesforce.com/.
